# Octane connector documentation

These documents cover the connectors built for Octane's local gbrain
deployment. They are separate from the upstream gbrain documentation in
`docs/`, which describes the product in general.

| Document | Purpose |
|---|---|
| [connectors/README.md](connectors/README.md) | Overview of the Octane connectors and how they share one design |
| [connectors/mcp-connection.md](connectors/mcp-connection.md) | How gbrain reads an existing MCP server connection |
| [connectors/slack-mcp.md](connectors/slack-mcp.md) | Slack channel history and thread replies |
| [connectors/jira-mcp.md](connectors/jira-mcp.md) | Jira issues and comments selected by JQL |
| [connectors/google-mcp.md](connectors/google-mcp.md) | Gmail messages and Calendar event summaries |

Upstream setup for the gbrain CLI, GitHub and embeddings remains in
[docs/setup/setup.md](../../setup/setup.md).
